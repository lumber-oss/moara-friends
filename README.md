# moara-friends

沫然Blog 的友链仓库。提交 PR 即可添加友链，自动校验、自动合并。

## 怎么添加友链

### 1. 先在你的友链页加上我的链接

在你的网站的友链页面，添加一个指向本站的链接：

```html
<a href="https://blog.945426.xyz/">沫然Blog</a>
```

或 Markdown：

```markdown
[沫然Blog](https://blog.945426.xyz/)
```

**这一步必须先做**——提交 PR 时会自动检查你的友链页有没有我的链接，没有的话 PR 会被拒绝。

### 2. Fork 仓库

点右上角 Fork，把仓库复制到你的账号下。

### 3. 新建友链文件

在你的 Fork 里，进入 `data/friends/` 目录，新建一个 JSON 文件。文件名随意，建议用你的站点名（如 `example.json`）。

### 4. 填写友链信息

按下面的模板填写：

```json
{
  "name": "站点名称",
  "avatar": "https://.../头像.png",
  "description": "简介/描述",
  "url": "https://你的站点",
  "backlink": "https://你的站点/友链页地址"
}
```

### 5. 提交 PR

提交代码，创建 Pull Request。机器人会自动校验：

- ✅ 检查你的友链页有没有我
- ✅ 检查你的站点能否访问
- ✅ 检查 JSON 格式是否正确

全部通过 → 自动合并，几分钟后友链就会出现在我的博客上。

校验失败 → 会在 PR 里评论告诉你哪里不对，改完 push 到该 PR 或者关闭重新打开会重新校验。

## 字段说明

| 字段 | 必填 | 说明 |
|---|---|---|
| `name` | ✅ | 站点名称 |
| `url` | ✅ | 站点地址，以 `https://` 开头 |
| `backlink` | ✅ | 你的友链页地址 |
| `avatar` | ❌ | 头像图片地址 |
| `description` | ❌ | 简介/描述 |

> `backlink` 填你自己网站上那个友链页的地址，不是首页。比如你的友链页是`https://example.com/links`，就填这个。
## 常见问题

**Q: 校验提示"反链验证未通过"怎么办？**

A: 说明在你的友链页里没找到我的链接。请确认：
1. 链接已经添加到友链页
2. 链接地址是 `https://blog.945426.xyz` 或 `https://blog.945426.xyz/`
3. 添加后可能需要等几分钟让 CDN 缓存刷新后再重新 push


**Q: 改了信息怎么更新？**

A: 同样提 PR 修改你的 JSON 文件就行。

**Q: PR 提交后多久能合并？**

A: 校验通过会立即自动合并，jsDelivr CDN 缓存刷新就能在我的博客看到。
